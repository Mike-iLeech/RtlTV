Установка и обновление

SDR4NOOB поставляется готовой сборкой для Windows: Python, Qt и драйвер librtlsdr уже внутри. Есть установщик (рекомендуется) и архив для запуска без установки.

Что нужно#

ЧтоТребование
СистемаWindows 10 или 11, 64 бит.
ПриёмникRTL-SDR Blog V4 или V3, другие донглы на RTL2832U. Дополнительно: HackRF One, Airspy R2/Mini (с их DLL), любой сервер rtl_tcp в сети. Без приёмника работает тестовый эфир.
ДрайверWinUSB на интерфейсе донгла (Zadig, один раз).
АнтеннаКомплектный диполь для начала; для спутников и самолётов — см. «Антенны и кабели».
ИнтернетНе обязателен. Нужен для подложки карт, орбит (TLE), справочника бортов и обновлений.

1. Установить#

  1. Откройте страницу последнего выпуска и скачайте установщик SDR4NOOB-<версия>-setup.exe.
  2. Запустите его. Мастер спросит три вещи:
    • Папка программы — по умолчанию %LOCALAPPDATA%\Programs\SDR4NOOB. Права администратора не нужны, и автообновление сможет само заменять файлы. Не выбирайте C:\Program Files.
    • Папка для ваших файлов — сюда программа складывает записи пролётов (до 2 ГБ каждая), снимки, записи звука и журналы. По умолчанию Документы\SDR4NOOB; удобно выбрать большой второй диск. Позже её можно сменить в «Настройках».
    • Автообновление — проверять ли раз в день новую версию на GitHub (ставится только с вашего согласия).
  3. Готово: SDR4NOOB появится в меню «Пуск» (и на рабочем столе, если отметили ярлык).

Без установки. Скачайте архив SDR4NOOB-<версия>-win64.zip, распакуйте целиком (правая кнопка → «Извлечь всё…») в папку с правами записи и запустите SDR4NOOB.exe. Не запускайте программу прямо из окна архиватора — распакуйте сначала.

Программа не подписана сертификатом разработчика, поэтому при первом запуске Windows SmartScreen может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае». Скачивайте SDR4NOOB только со страницы выпусков на GitHub.

2. Драйвер WinUSB (Zadig)#

Windows считает донгл ТВ-тюнером и ставит драйвер Realtek для DVB-T, с которым SDR-программы не работают. Один раз замените его на WinUSB. Если донгл уже работал в SDR#, SDR++ или SatDump — этот шаг не нужен.

  1. Скачайте Zadig с официального сайта zadig.akeo.ie и запустите.
  2. Options → List All Devices. Выберите «Bulk-In, Interface (Interface 0)» или «RTL2838UHIDIR». USB ID должен начинаться с 0BDA 2838.
  3. Справа выберите WinUSB и нажмите Replace Driver (или Install Driver).
Не выбирайте в Zadig другие устройства — клавиатура, мышь или звуковая карта перестанут работать. В другом USB-порту Windows может считать донгл новым устройством — тогда замену нужно повторить.

Проверить результат можно в SDR4NOOB: кнопка «Устройства…» на экране выбора режима показывает найденные приёмники, их VID:PID и драйвер Windows («Готово: работает со встроенным драйвером SDR4NOOB»). Подробнее — «Драйверы: WinUSB и Zadig».

3. Первый запуск#

  • Появится экран выбора режима: ТВ, Радио, SSTV, Спутники, Самолёты (ADS-B), APRS. Вернуться к нему — меню «Режим → Выбрать другой режим…» (Ctrl+M).
  • Галочка «Без антенны: тестовый эфир вместо донгла» включает синтетические сигналы для всех режимов.
  • Кнопка «Руководство» открывает встроенную справку (то же, что на этом сайте), F1 в окне режима — страницу этого режима.
  • Дальше — «Быстрый старт».

Другие приёмники#

  • RTL-SDR работает со встроенным librtlsdr (сборка rtl-sdr-blog с поддержкой V4). Ставить SDR# или системный librtlsdr не нужно.
  • HackRF One и Airspy R2/Mini: «Устройства… → Загрузить драйвер (DLL)…» — hackrf.dll или airspy.dll, плюс libusb-1.0.dll и pthreadVC2.dll. Файлы копируются в папку драйверов SDR4NOOB.
  • rtl_tcp: приёмник на другом компьютере — «Добавить сетевой rtl_tcp…» (адрес и порт). Подходят и совместимые серверы, например rsp_tcp для SDRplay.

Где лежат файлы#

ПапкаЧто в ней
Папка данных (по умолчанию Документы\SDR4NOOB)Записи IQ, снимки (ТВ, «Метеор», «Электро-Л», SSTV), звук (WAV), журналы ADS-B и APRS. Выбирается в «Настройках»; там же — перенос файлов из прежних мест.
%APPDATA%\SDR4NOOBНастройки (*.json).
%LOCALAPPDATA%\SDR4NOOBКэш карт, орбиты (TLE), история самолётов, справочник бортов, драйверы, журнал sdr4noob.log. По желанию — внутри папки данных («служебное тоже здесь»).

Обновление#

  • SDR4NOOB сам проверяет новую версию на GitHub Releases — по умолчанию раз в день (в «Настройках»: раз в день, раз в неделю или никогда). Проверить вручную — меню «Справка → Проверить обновления…» или «Настройки → Проверить сейчас».
  • В окне «Доступно обновление SDR4NOOB» видно описание изменений; кнопки «Обновить сейчас», «Страница релиза» и «Пропустить эту версию».
  • «Обновить сейчас» скачивает новую версию и сверяет контрольную сумму SHA-256. Если программа поставлена установщиком, новый установщик тихо ставит её в ту же папку; если она распакована из архива — после выхода программы заменяются файлы (прежняя версия сохраняется и возвращается при ошибке). Затем новая версия запускается сама. Настройки и папка данных не затрагиваются.
  • Вручную: запустите новый установщик (он найдёт прежнюю папку) или распакуйте новый архив поверх старой папки (программа должна быть закрыта).

Удаление#

Если ставили установщиком — «Параметры → Приложения → SDR4NOOB → Удалить»; ваши записи и настройки при этом остаются. Переносную версию: закройте SDR4NOOB и удалите папку программы. Чтобы не осталось следов, удалите также %APPDATA%\SDR4NOOB и %LOCALAPPDATA%\SDR4NOOB; папку данных со снимками и записями — по желанию. Драйвер WinUSB можно оставить: им пользуются и другие SDR-программы.

Из исходников#

Нужен Python 3.12 для Windows x64. Инструкция по запуску, сборке EXE и тестам — в README репозитория.
