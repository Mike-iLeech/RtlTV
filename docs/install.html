Установка и обновление

RtlTV поставляется готовой сборкой для Windows: Python, Qt и драйвер librtlsdr уже внутри. Установщика нет — архив распаковывается в любую папку.

Что нужно#

ЧтоТребование
СистемаWindows 10 или 11, 64 бит.
ПриёмникRTL-SDR Blog V4 или V3, другие донглы на RTL2832U. Дополнительно: HackRF One, Airspy R2/Mini (с их DLL), любой сервер rtl_tcp в сети. Без приёмника работает тестовый эфир.
ДрайверWinUSB на интерфейсе донгла (Zadig, один раз).
АнтеннаКомплектный диполь для начала; для спутников и самолётов — см. «Антенны и кабели».
ИнтернетНе обязателен. Нужен для подложки карт, орбит (TLE), справочника бортов и обновлений.

1. Скачать и распаковать#

  1. Откройте страницу последнего выпуска и скачайте RtlTV-<версия>-win64.zip (например, RtlTV-2.0.0-win64.zip).
  2. Распакуйте архив целиком (правая кнопка → «Извлечь всё…») в папку, куда у вас есть права записи: C:\RtlTV, D:\Программы\RtlTV и т. п. Не кладите программу в C:\Program Files — автообновлению нужно заменять файлы без прав администратора.
  3. Внутри будет папка с RtlTV.exe и служебной папкой _internal. Запускайте RtlTV.exe; при желании создайте ярлык на рабочем столе.
Программа не подписана сертификатом разработчика, поэтому при первом запуске Windows SmartScreen может показать «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае». Скачивайте RtlTV только со страницы выпусков на GitHub.

2. Драйвер WinUSB (Zadig)#

Windows считает донгл ТВ-тюнером и ставит драйвер Realtek для DVB-T, с которым SDR-программы не работают. Один раз замените его на WinUSB. Если донгл уже работал в SDR#, SDR++ или SatDump — этот шаг не нужен.

  1. Скачайте Zadig с официального сайта zadig.akeo.ie и запустите.
  2. Options → List All Devices. Выберите «Bulk-In, Interface (Interface 0)» или «RTL2838UHIDIR». USB ID должен начинаться с 0BDA 2838.
  3. Справа выберите WinUSB и нажмите Replace Driver (или Install Driver).
Не выбирайте в Zadig другие устройства — клавиатура, мышь или звуковая карта перестанут работать. В другом USB-порту Windows может считать донгл новым устройством — тогда замену нужно повторить.

Проверить результат можно в RtlTV: кнопка «Устройства…» на экране выбора режима показывает найденные приёмники, их VID:PID и драйвер Windows («Готово: работает со встроенным драйвером RtlTV»). Подробнее — «Драйверы: WinUSB и Zadig».

3. Первый запуск#

  • Появится экран выбора режима: ТВ, Радио, SSTV, Спутники, Самолёты (ADS-B), APRS. Вернуться к нему — меню «Режим → Выбрать другой режим…» (Ctrl+M).
  • Галочка «Без антенны: тестовый эфир вместо донгла» включает синтетические сигналы для всех режимов.
  • Кнопка «Руководство» открывает встроенную справку (то же, что на этом сайте), F1 в окне режима — страницу этого режима.
  • Дальше — «Быстрый старт».

Другие приёмники#

  • RTL-SDR работает со встроенным librtlsdr (сборка rtl-sdr-blog с поддержкой V4). Ставить SDR# или системный librtlsdr не нужно.
  • HackRF One и Airspy R2/Mini: «Устройства… → Загрузить драйвер (DLL)…» — hackrf.dll или airspy.dll, плюс libusb-1.0.dll и pthreadVC2.dll. Файлы копируются в папку драйверов RtlTV.
  • rtl_tcp: приёмник на другом компьютере — «Добавить сетевой rtl_tcp…» (адрес и порт). Подходят и совместимые серверы, например rsp_tcp для SDRplay.

Где лежат файлы#

ПапкаЧто в ней
Папка данных (по умолчанию Документы\RtlTV)Записи IQ, снимки (ТВ, «Метеор», «Электро-Л», SSTV), звук (WAV), журналы ADS-B и APRS. Выбирается в «Настройках»; там же — перенос файлов из прежних мест.
%APPDATA%\RtlTVНастройки (*.json).
%LOCALAPPDATA%\RtlTVКэш карт, орбиты (TLE), история самолётов, справочник бортов, драйверы, журнал rtltv.log. По желанию — внутри папки данных («служебное тоже здесь»).

Обновление#

  • RtlTV сам проверяет новую версию на GitHub Releases — по умолчанию раз в день (в «Настройках»: раз в день, раз в неделю или никогда). Проверить вручную — меню «Справка → Проверить обновления…» или «Настройки → Проверить сейчас».
  • В окне «Доступно обновление RtlTV» видно описание изменений; кнопки «Обновить сейчас», «Страница релиза» и «Пропустить эту версию».
  • «Обновить сейчас» скачивает архив, сверяет контрольную сумму SHA-256, после выхода программы заменяет файлы (прежняя версия сохраняется и возвращается при ошибке) и запускает новую версию. Настройки и папка данных не затрагиваются.
  • Вручную: скачайте новый архив и распакуйте поверх старой папки (программа должна быть закрыта).

Удаление#

Закройте RtlTV и удалите папку программы. Чтобы не осталось следов, удалите также %APPDATA%\RtlTV и %LOCALAPPDATA%\RtlTV; папку данных со снимками и записями — по желанию. Драйвер WinUSB можно оставить: им пользуются и другие SDR-программы.

Из исходников#

Нужен Python 3.12 для Windows x64. Инструкция по запуску, сборке EXE и тестам — в README репозитория.
