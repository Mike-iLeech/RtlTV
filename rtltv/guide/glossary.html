Словарь терминов

А · Б · В · Г · Д · З · И · К · Л · М · Н · О · П · Р · С · Т · Ф · Ц · Ч · Ш · Я · A–Z

А

Азимут — направление по компасу: 0° север, 90° восток, 180° юг, 270° запад. →

АМ (AM) — амплитудная модуляция: авиасвязь, вещание на ДВ/СВ/КВ. →

Антенна — проводник, превращающий радиоволну в напряжение на входе приёмника. →

АРУ — автоматическая регулировка усиления; в донгле две: тюнера и RTL2832. →

АЦП — аналого-цифровой преобразователь; у SDR обычно 8–16 бит (например, у RTL-SDR — 8). →

Б

БПФ (FFT) — быстрое преобразование Фурье, превращает отсчёты в спектр. →

Боковая полоса — часть спектра AM-сигнала выше (верхняя) или ниже (нижняя) несущей; SSB передаёт одну. →

В

V-диполь — диполь с плечами под 120°, горизонтально; простая антенна для «Метеора». →

VFO — «генератор плавного диапазона»: частота, которую сейчас слушают; на спектре — подсвеченная полоса. →

VIS-код — короткая метка в начале SSTV-картинки, по которой узнаётся её режим. →

Водопад — спектр, развёрнутый во времени: время идёт сверху вниз. →

Возвышение (элевация) — угол спутника над горизонтом. →

Г

Граунд-плейн (Ground Plane) — вертикальный штырь λ/4 с противовесами. →

Д

дБ — логарифм отношения: 10·lg для мощности, 20·lg для напряжения. →

дБi / дБd — усиление антенны относительно изотропной / диполя; дБi = дБd + 2,15. →

дБм — мощность относительно 1 мВт. →

дБмкВ — напряжение относительно 1 мкВ; на 50 Ом = дБм + 107. →

дБFS — уровень относительно полной шкалы АЦП. →

DC-пик — пик постоянной составляющей в центре полосы приёмника. →

Девиация — наибольшее отклонение частоты при ЧМ: ±75 кГц у WFM, ±2,5/±5 кГц у NFM. →

Децимация — понижение частоты дискретизации с фильтрацией; даёт выигрыш в шуме. →

Диполь — антенна из двух плеч по λ/4. →

Дискон — широкополосная вертикальная антенна «диск + конус». →

Динамический диапазон — отношение самого сильного неискажённого сигнала к самому слабому различимому. →

Доплеровский сдвиг — изменение частоты от движения передатчика; у спутников — единицы–десятки кГц. →

DMR — цифровой стандарт раций: 4FSK, два слота в канале 12,5 кГц. →

З

Защитный интервал (GI) — повтор конца символа OFDM в его начале для защиты от эха. →

Зеркальный канал — ложная копия сигнала, симметричная относительно центра полосы. →

И

I/Q — пары отсчётов (синфазный и квадратурный), описывающие амплитуду и фазу сигнала. →

ICAO-адрес — 24-битный уникальный адрес ответчика самолёта. →

Интермодуляция — ложные сигналы от смешения двух мощных в нелинейном усилителе. →

К

Коаксиальный кабель — кабель с центральной жилой и оплёткой; потери растут с частотой. →

Коэффициент укорочения — во сколько раз антенна короче теоретической λ/4 (≈0,95). →

Коэффициент шума (КШ, NF) — насколько приёмник ухудшает ОСШ. →

Круговая поляризация — поле вращается; так передают спутники. →

Л

LRIT — передача снимков «Электро-Л» на 1691 МГц (BPSK). →

LRPT — передача снимков «Метеор-М» на 137,9 МГц (OQPSK 72k). →

λ (лямбда) — длина волны: λ (м) = 300 / f (МГц). →

М

Мода S (Mode S) — система ответчиков самолётов на 1090 МГц, частью которой является ADS-B. →

Модуляция — способ нанести информацию на несущую. →

Мультиплекс — пакет из нескольких цифровых ТВ-каналов в одном частотном канале 8 МГц. →

МШУ (LNA) — малошумящий усилитель у антенны. →

Н

Несущая — немодулированная составляющая сигнала. →

NORAD-номер — каталожный номер спутника (МКС — 25544). →

О

OFDM — тысячи узких поднесущих одновременно; DVB-T2. →

ОСШ (SNR) — отношение сигнал/шум, дБ. →

П

Перегрузка — выход сигнала за шкалу АЦП или линейный диапазон усилителя. →

Пилот-тон — 19 кГц в FM-сигнале, признак стерео. →

PMR446 — безлицензионные рации 446,0–446,2 МГц. →

Полоса — ширина спектра сигнала или фильтра; также ширина обзора приёмника (полоса обзора). →

Поляризация — ориентация электрического поля волны. →

ppm — миллионная доля; погрешность частоты кварца. →

Предыскажения — подъём высоких частот при передаче FM (50 мкс в России). →

Р

RDS — данные о станции на поднесущей 57 кГц. →

Ретранслятор — станция, которая принимает и тут же передаёт на другой частоте, увеличивая дальность раций. →

Рида — Соломона код (RS) — исправляет ошибки в кадрах LRPT/LRIT; «Кадры без ошибок RS» — доля исправленных. →

С

SDR — программно-определяемое радио. →

SGP4 — модель расчёта положения спутника по TLE. →

Сквок — 4-значный код ответчика самолёта (7700 — бедствие). →

Слот — один из двух временных каналов DMR. →

Созвездие — точки фаз символов PSK; 4 чётких облака — QPSK пойман. →

Спектр — уровень сигналов по частотам. →

SSB — однополосная модуляция (USB/LSB). →

SSTV — медленное телевидение, картинки звуком. →

Т

TCXO — термокомпенсированный кварцевый генератор (~1 ppm у V4). →

Телеграф (CW) — азбука Морзе включением несущей. →

TLE — две строки параметров орбиты спутника. →

Транспондер — ретранслятор на спутнике, переносящий полосу частот вверх-вниз. →

Тюнер — микросхема, переносящая нужный участок эфира на низкую частоту (например, R828D у RTL-SDR Blog V4). →

Ф

Фильтр — пропускает нужные частоты и ослабляет остальные; FM-режектор вырезает 88–108 МГц. →

Ферритовое кольцо — защёлка на кабель, гасит высокочастотные помехи по оплётке. →

FSK / 4FSK / AFSK — частотная манипуляция; 4FSK — DMR, AFSK — APRS. →

Ц

Цветовой код (CC) — число 0–15 в DMR, отличает ретрансляторы на одной частоте. →

Ч

Частота дискретизации — сколько отсчётов в секунду; у SDR-приёмника равна ширине видимого спектра. →

ЧМ (FM) — частотная модуляция: WFM (вещание) и NFM (рации). →

Чувствительность — самый слабый сигнал, который приёмник ещё принимает. →

Ш

Шумодав (squelch) — выключает звук, пока сигнал ниже порога. →

Шумовая дорожка — «ковёр» шума внизу спектра. →

Я

Яги (Яги — Уда) — направленная антенна с директорами и рефлектором. →
